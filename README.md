# АбсолютПрофРемонт - Сайт строительной компании

Корпоративный сайт строительно-ремонтной компании с CMS-функционалом и интерактивным личным кабинетом заказчика с системой онлайн-отслеживания ремонта

## Технологии

- **Frontend**: Next.js 15, React 19, TypeScript
- **Styling**: Tailwind CSS v4, shadcn/ui
- **Database**: Supabase (PostgreSQL)
- **Authentication**: Supabase Auth
- **Deployment**: Railway

## Структура проекта

### Публичные страницы
- `/` - Главная страница с основными разделами
- `/register` - Страница регистрации
- `/login` - Страница авторизации
- `/services` - Каталог услуг компании
- `/portfolio` - Портфолио выполненных проектов
- `/portfolio/[id]` - Детальная страница проекта
- `/about` - О компании и команде
- `/reviews` - Отзывы клиентов (виджет Flamp)
- `/contacts` - Контакты и формы обратной связи
- `/privacy` - Политика конфиденциальности
- `/dashboard` - Личный кабинет пользователя

### Админ-панель
- `/admin` - Главная панель со статистикой
- `/admin/login` - Страница входа
- `/admin/client-projects` - Проекты клиентов
- `/admin/client-projects/new` - Создание и редактирование проекта клиента
- `/admin/client-projects/[id]` - Дополнительная страница для загрузки фото и видеоматериала проекта для прорабов
- `/admin/services` - Управление услугами
- `/admin/projects` - Управление проектами
- `/admin/team` - Управление командой
- `/admin/contacts` - Просмотр обращений
- `/admin/consultations` - Просмотр заявок на консультацию
- `/admin/settings` - Настройки сайта

## База данных

### Таблицы
- `services` - Услуги компании
- `projects` - Портфолио проектов
- `project_images` - Галерея изображений проектов
- `team_members` - Сотрудники компании
- `contact_requests` - Обращения с формы контактов
- `consultation_requests` - Заявки на консультацию
- `site_settings` - Настройки сайта
- `client_projects` - Проекты клиентов
- `order_status_history` - История статуса заявки
- `orders` - Заявки (проекты заказчиков)
- `profiles` - Профили пользователей
- `stage_media` - Фото/видео проектов для отображения в статусе проекта

### Безопасность
- Включен Row Level Security (RLS) на всех таблицах
- Публичный доступ только на чтение опубликованного контента
- Формы доступны без авторизации
- Админ-панель требует аутентификации
- Личный кабинет требует аутентификации

## Интеграция с Flamp

Сайт использует официальный виджет Flamp.ru для отображения отзывов клиентов.

Виджет автоматически загружает актуальные отзывы напрямую с Flamp - никакой базы данных для отзывов не требуется.

### Как работает

- Виджет встроен на страницу `/reviews`
- Отзывы загружаются напрямую с Flamp.ru
- На главной странице есть ссылка на Flamp для написания новых отзывов

## Интеграция с Telegram

На сайте реализован телеграмм бот который отправляет уведомление менеджеру о отправленной заявке на телефон, с данными клиента.

Так же телеграмм бот работает и с клиентами, при изменении статуса проекта клиенту на телефон приходит уведомление в телеграмм о "изменении статуса проекта".

### Как работает

- Заявки загружаются сразу после отправки формы, в телеграмм и БД
